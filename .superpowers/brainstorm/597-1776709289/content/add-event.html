A — Cliquer sur un jour

On clique directement sur une case du calendrier pour y créer un événement. La date est pré-remplie automatiquement. Intuitif, style Google Calendar.

B — Bouton "Ajouter"

Un bouton fixe dans l'en-tête du calendrier ouvre un formulaire. La date est à choisir manuellement dans le formulaire. Plus explicite pour l'admin.

C — Les deux

Bouton dans l'en-tête ET clic sur une case du calendrier. Le clic sur un jour pré-remplit la date. Le bouton laisse tout remplir manuellement.
